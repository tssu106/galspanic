# One More Inch (한뼘더) — Co-op

원작 아케이드 **갈스패닉(Qix 계열)** 을 최대한 비슷하게 구현한 웹 게임. 안전지대에서
빈 공간으로 들어가 **선**을 긋고, 선이 다시 안전지대에 닿으면 안쪽이 **폐곡선 flood-fill**
로 한 번에 점유되어 숨겨진 그림이 드러납니다. 돌아다니는 **적**이 당신의 선에 닿으면
목숨을 잃습니다. 화면의 **80%** 를 열면 클리어!

> 📋 **진행 현황**은 [`PROGRESS.md`](PROGRESS.md) 또는 브라우저로 [`client/status.html`](client/status.html) 을 열어 확인하세요.

두 가지 방식으로 즐길 수 있습니다.

| 모드 | 파일 | 멀티플레이 | 서버 필요 |
|------|------|-----------|-----------|
| **로컬 한 화면** | `client/local.html` | 한 PC에서 2~4명 (각자 다른 키) | ❌ 바로 실행 |
| **온라인** | `server/` + `client/index.html` | 각자 PC에서 접속 (최대 4명) | ✅ Colyseus |

---

## 1) 로컬 한 화면 (가장 빠름)

`client/local.html` 을 브라우저로 열기만 하면 됩니다. (더블클릭 또는 `npx serve client`)

- **P1** 방향키 · **P2** `WASD` · **P3** `IJKL` · **P4** 숫자패드 `8/5/4/6`
- 메뉴에서 숫자키 `1~4` 로 인원 선택 후 시작 · `P` 일시정지 · `R` 재시작
- 레벨을 깰수록 적이 늘고 빨라지며, 새 그림이 나옵니다. 기여도(점유율) 순으로 순위 표시.

## 2) 온라인 (서버 권위 동기화)

### 서버
```bash
cd server
npm install
npm start        # ws://localhost:2567
```
(선택) 흐린 배경 이미지를 `server/public/images/<id>_blur.jpg` 로 넣으면 그 그림이 공개됩니다.
없으면 단색으로 대체됩니다.

### 클라이언트
`client/index.html` 을 여러 개 열면 같은 방에 접속됩니다.
```bash
npx serve client        # 로컬 파일 CORS 회피
```
- **방향키/WASD** 로 이동. 클리어/게임오버 후 `Enter` 로 다음 레벨/재시작.

## 구조 & 설계

```
client/
  local.html   로컬 멀티 (엔진+렌더+입력 all-in-one, 서버 불필요)
  index.html   온라인 클라이언트 (입력만 전송, 동기화된 상태를 렌더)
server/src/
  GalSim.ts    서버 권위 Qix 시뮬레이션 (DOM-free, local.html 엔진의 포팅)
  GameRoom.ts  틱 루프(~30Hz)로 GalSim 구동 → Colyseus 스키마에 델타 동기화
  schema.ts    동기화 상태(grid/trail/players/enemies/phase/level)
  constants.ts 그리드/보더/속도/목표치 등
```

**핵심 메커니즘 (두 모드 공통)**
- **선 긋기**: 안전지대(claimed) → 빈칸(empty)으로 이동하면 그 칸에 자기 소유의 trail을 남김.
- **폐곡선 점유**: 선이 다시 안전지대에 닿는 순간, trail을 벽으로 굳히고 **적 위치에서 flood-fill**
  → 적이 닿을 수 없는 빈 영역을 전부 점유. (원작처럼 적을 좁은 곳에 가두면 크게 먹습니다.)
- **적**: 빈 공간에서 벽에 튕기며 이동, trail에 닿으면 그 선의 주인이 사망(목숨 -1, 부활).
- **승리**: 내부(interior)의 80% 점유. 각 플레이어 점유 칸으로 기여도/순위 산정.

**온라인 설계 포인트**
- **서버 권위**: 클라는 방향 코드(0~4)만 보내고, 서버 `GalSim` 이 이동·충돌·점유를 계산.
  Colyseus가 변경된 셀만 델타로 전 클라에 동기화 → 치트/불일치 방지.
- **이미지 보안**: 원본 풀해상도는 클라에 안 보냄. 흐린 버전만 배포하고 열린 셀만 선명하게.
  (다음 단계: 열린 타일만 서버에서 잘라 스트리밍해 완전 차단.)
